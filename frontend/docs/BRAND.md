# ImpactOS mark

The split-path symbol represents one proposed change branching into downstream effects. It uses a solid geometric silhouette that stays readable at navigation and favicon sizes.

- Shared component: `Mark` in `src/components/ui.tsx`
- Standalone vector: `public/impactos-mark.svg`
- Browser icon: `src/app/icon.svg`
- Brand orange: `#ff5c35`

Use the mark upright with clear space around it. The wordmark remains in Geist. The same symbol appears in the homepage, demo header, footer, and product illustrations.
